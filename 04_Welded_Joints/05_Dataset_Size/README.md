# Study 4 — Welded Joints: Dataset-Size Sensitivity

This directory contains the fixed deep neural network (DNN) dataset-size sensitivity analysis for prediction of numerical welded-joint **moment resistance**. It assesses the relationship between the number of available training observations and model performance, without a new hyperparameter search.

## Dataset

The script reads `data/study_04_data.xlsx` relative to the repository root. The database must include the 15 predictors listed in `INPUT_COLUMNS` and the target `moment resistance`. Rows with missing required values are removed. Optional sparse-bin filtering is defined but **disabled** (`USE_DATA_FILTERING = False`). Dataset redistribution should follow the applicable permissions.

## Procedure

The database is partitioned once, using an 80/20 training/test split and random seed 42. A seeded permutation of the training pool defines **nested** subsets: the larger subsets contain the smaller ones. Requested sizes are 100, 200, 400, 600, 800, 1,000, 1,200, 1,600, and the complete training pool (`full`); sizes above the available pool are skipped. The same fixed test partition is evaluated for every size.

Each subset trains a DNN with architecture **64–32–16**, GELU activation, AdamW optimization (learning rate **0.005**, weight decay **0**), and relative-squared-error loss. Inputs are standardized using statistics from the current training subset only. Outputs are scaled by the current subset's maximum target, as `y_scaled = 10 × y / max(y_train)`. The initialization seed is reset to 42 for each run. The model is trained for **5,000 epochs**, recording training and test metrics at epoch 1 and every 25 epochs.

**Interpretation of the reported results:** The script records both the final-epoch metrics and the epoch with the **lowest test CoV** for each subset. Because the held-out test partition is repeatedly monitored and used to identify the best reported epoch, the `best_test_*` metrics are **test-monitored exploratory statistics**, not estimates from a fully untouched independent test set. The `final_test_*` results at the predefined 5,000th epoch do not use this best-epoch rule. The analysis is a single-seed dataset-size experiment; it does not perform cross-validation or repeated random sampling at each size.

## Run

From the repository root, with the required packages installed:

```bash
python 04_Welded_Joints/05_Dataset_Size/dataset_size_sensitivity.py
```

## Generated results

The script writes files locally under `outputs/`, including:

- `dataset_size_dnn_results.csv`: best-test-CoV epoch and final-epoch metrics for each training size
- `dataset_size_dnn_epoch_history.csv`: recorded training/test metrics across epochs
- `dataset_size_dnn_summary.txt`: model settings, data sizes, and summary statistics
- Six PNG plots: test CoV and R² against dataset size, and training/test CoV and R² against epoch

The output files are generated by the script and are excluded from version control by the local `.gitignore`. Numerical results depend on the underlying dataset, library versions, and execution hardware; the script has been syntax-checked but the original analysis has not been rerun here.
