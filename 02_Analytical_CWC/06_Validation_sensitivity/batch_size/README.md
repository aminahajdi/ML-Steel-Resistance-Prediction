# Study 2 — Analytical CWC

## Batch-size sensitivity

This study compares full-batch, 512 and 1024 observations per batch using an 80/20 split and five-fold CV in the training portion. The fixed architecture is (256, 128, 64) with GELU, AdamW, learning rate 0.001 and weight decay 0.0001. The experiment records cross-validation and independent-test performance for each batch size.

From the repository root, run:

```bash
python 02_Analytical_CWC/06_Validation_Sensitivity/batch_size/batch_size_sensitivity.py
```

The analytical data file must be placed at `data/study_02_data.xlsx`, retaining input names and record order. Outputs generated by a run are saved under `outputs/`. Existing results are retained under `reference_results/` and have not been reproduced during code organization.
