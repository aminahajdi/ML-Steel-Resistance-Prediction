# Study 2 — Analytical CWC

## Fold-count and epoch-limit sensitivity

This study compares fold settings 1, 5, and 10 and maximum epochs of 2,000, 5,000, and 10,000 (subject to settings in the script), with an 80/20 outer split. The `1` setting is implemented using an internal validation split rather than a conventional single-fold KFold. Full-batch training is used. The fixed DNN has architecture (256, 128, 64), GELU, AdamW, learning rate 0.001 and weight decay 0.0001.

From the repository root, run:

```bash
python 02_Analytical_CWC/06_Validation_Sensitivity/fold_epoch/fold_epoch_sensitivity.py
```

The analytical data file must be placed at `data/study_02_data.xlsx`, retaining input names and record order. Outputs generated by a run are saved under `outputs/`. Existing results are retained under `reference_results/` and have not been reproduced during code organization.
