# Study 2 — Analytical CWC

## Train/test split sensitivity

This study compares 90/10, 80/20 and 70/30 splits. Within each training subset, five-fold CV supports DNN validation; final test metrics are calculated for the corresponding held-out subset. Because the test set changes with the split fraction, the test metrics are not evaluations against an identical test population.

The fixed architecture is (256, 128, 64) with GELU, AdamW, learning rate 0.001 and weight decay 0.0001; mini-batch size is 1024. See the script for epoch evaluation and early stopping.

From the repository root, run:

```bash
python 02_Analytical_CWC/06_Validation_Sensitivity/train_test_split/train_test_split_sensitivity.py
```

The analytical data file must be placed at `data/study_02_data.xlsx`, retaining input names and record order. Outputs generated by a run are saved under `outputs/`. Existing results are retained under `reference_results/` and have not been reproduced during code organization.
