# Study 2 — Validation sensitivity

These scripts investigate the sensitivity of fixed DNN models to three aspects of evaluation and training on the analytical CWC database. They accompany *A Systematic Framework for Machine Learning-Based Structural Resistance Prediction*.

| Analysis | Script | Settings compared |
|---|---|---|
| Train/test split | `train_test_split/train_test_split_sensitivity.py` | 90/10, 80/20, 70/30 |
| Batch size | `batch_size/batch_size_sensitivity.py` | Full batch, 512, 1024 |
| Fold count and epoch limits | `fold_epoch/fold_epoch_sensitivity.py` | 1, 5, 10 folds; 2,000, 5,000, 10,000 epochs |

All three use the fixed DNN architecture 256–128–64, GELU activation, AdamW optimizer, learning rate 0.001 and weight decay 0.0001. Input and target preprocessing are fitted on the relevant training partitions. The scripts retain the sequential sparse-tail filtering procedure used for analytical CWC.

## Data and execution

Place the analytical CWC database at `data/study_02_data.xlsx` in the repository root. Preserve its original columns, units and row order. Install dependencies from the repository root, including `torch`, `numpy`, `pandas`, `matplotlib`, `scikit-learn` and `openpyxl`. Run one analysis at a time, for example:

```bash
python 02_Analytical_CWC/06_Validation_Sensitivity/batch_size/batch_size_sensitivity.py
```

Each script writes numerical CSV and text summaries and figures into its own `outputs/` directory. Supplied outputs from prior runs are placed under `reference_results/` for traceability. They have not been regenerated by packaging these scripts.

## Interpretation

The train/test split study changes the identity and size of its holdout set, so independent-test metrics reflect both training size and test composition. The fold/epoch script treats the 1-fold setting as a separate internal validation split, not conventional one-fold cross-validation. Cross-validation metrics and held-out test metrics should not be interchanged. Refer to the paper for the interpretation of these sensitivity studies.

For strict numerical reproduction, use the approved original-order dataset and document the tested library versions; PyTorch results can vary with environment and hardware.
