# Study 3 — Experimental CWC: Database Analysis

This section accompanies *A Systematic Framework for Machine Learning-Based Structural Resistance Prediction* and provides two dataset diagnostics:

- `01_Correlation_Matrix/` — Pearson correlation analysis on the curated experimental CWC dataset.
- `02_Histograms/` — input-variable ranges and histograms of eight input features and experimental resistance.

Both analyses use the separately distributed workbook `data/study_03_data.xlsx`. Each subdirectory provides an execution command, methodological notes, and reference outputs. Scripts write newly generated files to their respective `outputs/` directories.
