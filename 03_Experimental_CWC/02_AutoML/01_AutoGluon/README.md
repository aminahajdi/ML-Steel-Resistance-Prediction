# Study 3 — Experimental CWC: AutoGluon benchmark

This directory contains the AutoGluon regression benchmark for experimental column-web transverse-compression (CWC) resistance prediction. The code accompanies *A Systematic Framework for Machine Learning-Based Structural Resistance Prediction*.

## Dataset

Download the separately distributed experimental dataset and save it as `data/study_03_data.xlsx` at the repository root. Required inputs are `h_c`, `t_wc`, `b_fc`, `t_fc`, `r_c`, `t_fb`, `N/Npl`, and `f_y`; the response is `F_exp`. Retain the original observation order, column names, and units.

The benchmark selects complete cases and positive resistance values, removing missing and infinite values. **It does not additionally exclude the maximum-resistance observation.** The dataset analysis scripts used elsewhere in Study 3 do exclude that observation; check which sample population corresponds to the results reported in the paper before making reproducibility claims.

## Training and evaluation

- Training/test partition: 80/20, split seed 7.
- Framework: AutoGluon Tabular, regression, RMSE as the AutoGluon evaluation metric.
- Preset: `best_quality`; time budget: 3,600 seconds (one hour).
- Training options: 5 bagging folds, one stacking level, CPU (`num_gpus=0`).
- AutoGluon selects its preferred model using its internal evaluation. The test leaderboard is descriptive and must **not** be used to select a model for final reporting.
- The script reports training and independent-test bias, coefficient of variation (CoV), R², RMSE and MAE. Bias and CoV use predicted/reference ratios (population standard deviation).
- Test-set permutation feature importance is calculated for AutoGluon's selected predictor; it is a post-hoc interpretation of test data, not part of model training.

A fixed split seed does not fully determine AutoGluon's internal stochastic training or model selection; software versions, configuration, and hardware can affect the outputs.

## Run

Install the repository dependencies, including an appropriately tested version of `autogluon.tabular`, `openpyxl`, `numpy`, `pandas`, and `scikit-learn`. From the repository root:

```bash
python 03_Experimental_CWC/02_AutoML/AutoGluon/autogluon_benchmark.py
```

## Generated files

The script writes to `outputs/seed_7/`:

| Output | Contents |
| --- | --- |
| `autogluon_leaderboard_seed7.csv` | Models and their evaluation statistics on the test subset |
| `best_model_metrics_seed7.csv` | Selected model's training and test metrics |
| `feature_importance_seed7.csv` | Permutation feature importance on the test subset |
| `AutoGluonModels/` | Trained models and framework artifacts |

Figures, SHAP analyses, extended leaderboards and additional model-interpretation outputs require separate scripts; they are not generated by `autogluon_benchmark.py`.

For the full methodological context and interpretation, refer to the accompanying paper.
